# Crossed assay implementation review before acquisition

Status: accepted

Reviewed 10 October 2026 against protocols 000, 011 and 012,
`configs/crossed-v1.json`, the saved developmental calibration assessment, the
crossed design receipt, and `docs/source_review.md`. This review concerns
prospective readiness. It acquires no crossed response, revises no frozen
measurement, and makes no ecological benefit claim.

The independent design receipt reports 160 complete starts, 80 complete
preparations, 23,920 effective-state comparisons, 12,000 reserved comparison
checks, and 20 retained aliases, with no mismatches. The saved protocol 011
calibration passes all five gates. Those are existing qualification facts,
not response outcomes from the crossed assay. The earlier protocol 010 gate
failure remains unchanged.

The source inventory precedes eligibility and search admission. C retains
every detected core, Q counts each eligible source at most once after two
unchanged isolated transmission edges, and R = C − Q includes ineligible,
unsearched and nonconfirming sources. Unknown source identity is retained even
when a known descendant qualifies; shared and noncontractible components are
excluded from isolation without disappearing from C. Root reproduction,
isolated extinction, search censoring, unresolved inheritance, ambiguous ancestry
and pending benefit are separate fields. Empty inventories are measured zeros;
an absent undisturbed denominator produces an undefined retention measure.
These envelopes concern recoverable detected source bodies under imposed
isolation, not total native viability, detector sensitivity or genetic parentage.

The arithmetic preserves five-snapshot integer totals for each paired condition.
Retention is Q_D/C_U to C_D/Q_U, with an undefined lower measure when C_U is zero
and an unbounded upper endpoint when Q_U is zero. Each panel averages eight
per-condition exact Fractions; totals are never pooled across conditions.
Disturbed population envelopes average the five snapshot counts separately.
Relative and absolute robust criteria compare each candidate with both of its
originating inputs in both panels, using strict inequalities. A failed numerical
robust criterion does not establish absence of biological advantage; overlap,
missingness and failed qualification leave that biological inference unresolved.
Candidate classifications link only to their actual catalogue encounter and
preserve all 36 main, 18 held-out and 54 overall encounter denominators. The other
16 candidate encounters retain unresolved inheritance/benefit; a zero confirmed
numerator is not a measured zero biological beneficial-variant yield.

The design crosses every declared age with every layout before aggregation.
Age contrasts hold placement fixed; layout contrasts hold the saved source phase
fixed, while including the layout's specified removed-clone position. Signed
interval subtraction and differences of age differences preserve undefined and
unbounded endpoints. Elapsed ages are not homologous reproductive phases, and
the E/F layout contrast does not independently replicate the A/B treatment.
The panels remain deterministic nested configurations. They cannot establish
independent-population uncertainty, H1, H3, an identified crowding mechanism,
increased evolvability or recursive self-improvement.

Cache keys bind complete component state, measured input identity, pinned rule,
isolation configuration and original-versus-any-identity endpoint. Chronological
time and lexicographic core order determine each world's first 128 distinct
eligible admissions. Cached keys consume local admission; repeated observations
retain their multiplicities; eligible keys beyond the cap remain unresolved even
when globally cached. All eligible complete root patches are saved, including
unsearched ones. Completed world and search receipts bind their evidence bytes
to both design and readiness. Reuse is deterministic computation, never
replication.

Readiness refuses existing response artifacts and binds the runner, independent
response verifier, arithmetic implementation, tests, validation, originating
encounter records and this review. Both benchmark and acquisition require
committed identical design, readiness, implementation, validation, review and
origin-record bytes; main acquisition also requires a passed one-worker
benchmark. Resume preserves the original acquisition record.
External memory guarding and sequential acquisition, auditing, rendering and Git
packing remain execution requirements; readiness does not authorize concurrent
heavy work or expanding search budgets.

An acquisition blocker was found and corrected before readiness: the inherited
physical digest hashes flattened array bytes without dimensions or element type.
It therefore cannot alone identify a complete isolated input; equal bytes in
different rectangular shapes can have different deterministic futures. The
crossed cache key and receipts now bind shape and type as well as cell bytes,
source rows retain those fields, and saved-root reuse compares full arrays and
types. This correction belongs to the new crossed implementation; earlier frozen
measurements remain unchanged. Synthetic same-bytes/different-shape and element-
type fixtures cover distinct keys, and a mismatched saved-root fixture covers
rejected reuse. Identity, endpoint and configuration distinctions also remain
part of the complete-input key.

The independent response auditor is complete. It checks the prospectively
committed design and readiness inventory, reconstructs every native structural
sample and census, validates complete extraction by independent occupied-cell
flood fill, checks the local admission schedule, and replays every executed
serial search using the existing independent dense verifier. It independently
recomputes cell, panel and contrast arithmetic, controls, joint gates, and original
encounter denominators. Per-unit proofs bind their physical evidence and verifier
dependencies before reuse; changed evidence invalidates a proof. Memory stops
are recorded as interruptions with zero mismatches, separately from verification
failure.

The auditor shares the pinned transition engine and periodic detector as
measurement references, without importing production crossed acquisition or
arithmetic helpers. These checks establish consistent execution and evidence
integrity; they do not establish universal detector sensitivity or native genetic
ancestry. The existing independent transition-rule verification remains the
physics reference.

The root-coordinated guarded preflight records all 63 tests passing in
`data/crossed-v1/implementation-validation.txt`. Reviewed fixtures distinguish
measured zero from missing or unbounded control values, verify exact per-condition
averaging and signed interactions, retain unknown and excluded sources, enforce
cached-key admission, refuse changed receipts and proofs, preserve failed
calibration and control gates, reject complete-input shape/type collisions, and
verify the actual catalogue origins and original denominators. All identified
implementation blockers are addressed. No crossed response or heavy simulation
was acquired as part of this review; a committed readiness receipt and one-worker
benchmark remain required before main acquisition.
