# Independent review of the prospective coverage design

Date: 10 October 2026. Reviewed before new source selection or recovery acquisition:
protocol 010, configs/coverage-v1.json, scripts/coverage_protocol.py and the design
receipt in data/coverage-v1/manifest.json. A separate review agent examined the
scientific contract, source sampling, extraction, isolation and provenance without
editing artifacts or running simulations.

The review accepts the design freeze: 40 paired worlds, 30 phase controls and
93 bound file hashes verify. The sampling and simulation ceilings agree. The
delay-zero scored gate avoids treating ecological losses at later delays as a
source-time assay failure. Omitted source classes remain separate from descendant
identities; recovery of a registered descendant is recoverability evidence, not
necessarily novel inheritance. Coordinate selection is diagnostic, not a
representative estimate of omitted viable population. D/U selected-root contrasts
remain descriptive. Earlier registries and benefit outcomes remain unchanged.

Readiness validation must explicitly test the identity used to initialize each
delayed search. Keep the original source class immutable and record the delayed
snapshot's measured identity separately. Null initialization applies to an
unknown isolated snapshot; an identifiable delayed snapshot supplies its measured
identity. Document this operational reading of protocol 010's unknown-root clause
in the implementation-readiness receipt, with a fixture that matures from unknown
to identifiable before isolation. This avoids an accidental extra transmission
requirement based only on the original source label. No acquisition code or
readiness receipt is approved by this design review.

The independent review also requires retention of sampled loss followed by
recurrence, empty strata, shared/unextractable selections and all search caps.
Unknown genotype alone is not core loss. Native matching words, root reproduction,
stable transmission and benefit remain distinct observations. No new benefit
confirmation or independent-population inference follows from this freeze.
