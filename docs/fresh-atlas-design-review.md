# Prospective review of the fresh atlas

Independent scientific review took place before EXP-panel-discovery-002 and
before EXP-atlas-002 acquisition. It checked protocol/code consistency, native
provenance, serial transmission, full components, periodic measurement, phase
eligibility, controls, and finite-panel inference.

Before discovery execution, review corrected the imported N01 trial to use its
original 11×13 native source component rather than an assay-derived descendant.
Third-generation size eligibility and frozen-source hashes are checked. The
periodic detector has seam-translation tests for S13, N01, and a recorded
rectangular transient, as well as shared-component rejection and translated
100-update replay. Earlier frozen modules and outcomes are unchanged.

The atlas design has nine ordered pairings and144 complete states, with matched
640-square worlds. Candidates require a word different from both inputs; a
catalogue identity different from the two inputs can qualify without being
globally new. Morphology-only changes are counted but not isolated, making the
endpoint conditional on a native-word screen. The expanded search retains
unsearched paths as unresolved. Held-out contrasts assess configuration
transfer, not independent organism histories. Snapshot validation is centered,
and discovery/configuration/protocol/code hashes are enforced before execution.
