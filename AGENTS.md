# Research instructions

This repository asks where evolvability resides across organisms, encounters,
and ecological history. Preserve the scientific contract in protocols/000.
H1 and H3 are untested until independent-population experiments are completed.
Identical complete deterministic states have identical futures. Population
growth, adaptation, or complexity increase alone does not demonstrate RSI.

Before each main batch, freeze a versioned protocol and JSON configuration,
including sampling units, horizon, control states, outcome rules, exclusions,
inheritance criteria, and benefit assay. Separate exploratory from main and
held-out encounters. Never omit lethal/nonproductive runs. Mark censoring,
unknown genotype, ambiguous ancestry, unresolved inheritance, and pending
benefit separately. Do not use deterministic reruns as independent samples.

Faithful synchronous nine-state CTRBL rules are pinned to the reference.
External interventions occur only in named treatments or declared isolation
assays. Retain complete starting grids, source/rule/configuration hashes,
event times, snapshots, and compact evidence. No normal exhaustive histories.
Maintain at least 200 MiB available memory; start with one worker, benchmark
before increasing batch size. Do not change physics to make a result appear.

Use conservative component extraction: retain arms and reject multicore
components. Legacy experiments reject boundary-spanning components; new
protocols may use validated periodic unwrapping when an empty row and column
exist and the entire single-core component is retained. Reject noncontractible
components. Allow transient-to-stable paths; preserve old frozen measurements.
Operational phase-normalized channel genotypes preserve spacing and chirality;
they are not automatically published species identifiers or full organism state.
Ancestry labels are causal overapproximations, not genetic parent assignments.

For candidate-fate calibration, preserve protocol 004's exact source core and
sampled loss/recurrence labels. Compare legacy and expanded searches on identical
components. Respect offspring, depth, and simulation caps; unsearched paths
remain unresolved. Native matching-word appearance is structural evidence,
not inherited offspring. Keep positive-control recovery and candidate novelty
as separate endpoints, and retain ineligible delays in the denominator.

For ecological scores, distinguish fixed-registry core counts from total viable
population. Freeze registry, recovery gate, prepared states, and comparison
criteria before acquisition. Compare both recovered identities against both
originating inputs; preserve exact integer totals so ties fail. Record actual
occupied-cell removal and population impact, including no-op interventions.
Check effective challenge equivalence under rotation/translation before treating
reserved conditions as new confirmation. A frozen numerical criterion can be
met while distinct ecological confirmation remains unresolved; retain both
facts without rewriting frozen outcomes. Use paired undisturbed controls and
declared preparation phases to separate baseline multiplication from recovery.

Update README, RESEARCH_STATE, manuscript, and figures after scientific batches.
Write README and manuscript for a researcher encountering the work for the
first time. Develop the scientific argument: explain the phenomenon and prior
work, the unresolved question, why each comparison addresses it, the observed
results, and their implications. Define technical terms before using them.
Keep the three hypotheses connected to their experimental comparisons; describe
future comparisons as a research programme rather than repeating status labels.
The project's purpose is understanding the causes of evolvability. Conference
targets belong in submission planning, not the scientific opening or abstract.
Use results tables and recorded-data figures with explanatory captions. Preserve
negative results, denominator distinctions, assay qualifications, and uncertainty
where they affect interpretation. Never improve the narrative by changing facts.
Put installation, runtime, dependency, checkpoint, and execution details in
docs/reproducing-results.md or RESEARCH_STATE.md. Include such details in the
scientific account only when they affect the method or inference. Update the
interpretation of findings after a batch instead of appending an activity log.
Prior art includes crossed competition, interaction-mediated variation,
inherited mutation bias, and disturbances. State the narrower addition precisely.
Read docs/source_review.md; check licenses before adding code or artwork.
Link papers, never redistribute unlicensed PDFs. Preserve vendored Apache notices.

Chromatic Fields / Midnight Blue uses configs/style.json as the single source
for all visual roles. Use dark navy backgrounds, blue text, shared sequential
blue scales, and the configured status/annotation colors. Import theme, THEMES,
quantitative_cmap, and annotation_color from scripts.figures; do not choose
local colors or built-in rainbow scales. README, replays, and paper figure pages
use the dark exports. Retire obsolete light exports when regenerating the set.
Literal cell-state colors and lineage overlays are separate. Render crisp cells with exact geometry; label time,
scale, encoding, denominators, missingness, and experimental status. Use labels and hatching alongside color; preserve exact cell-state mappings
and the distinction between missing observations and measured zero. Every figure records experiment IDs and regeneration
command in figures/manifest.json. Review rendered outputs before publication.

The user authorizes commits and pushes to ReloadLightly/evoloop-levels.
Use main unless protected. Preserve remote changes, never force-push. Verify
remote commit. Do not send email or other messages without explicit permission.
Delegate independent source verification or scientific/visual review when useful.

For standardized impact treatments, clone complete phase components including
arms, reject disconnected residual cells, and label constructed colonies explicitly.
Declared elapsed ages are not automatically homologous reproductive phases.
Verify one-third cell-state histogram and core loss before acquiring responses.
Retention panels average exact per-condition D/U Fractions; never pool totals.
Keep absolute disturbed advantage and all calibration/exposure/confirmation gates
separate. D>U is a measured outcome, not an identified crowding mechanism.
Run acquisition, independent audits, rendering, and Git packing sequentially under
the memory guard; retain interrupted invocation logs and resume completed cases.
